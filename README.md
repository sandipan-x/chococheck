# ChocoCheck

Free dog chocolate toxicity calculator: instant theobromine dose (mg/kg), risk level, per-type comparison and emergency steps. No signup.

## Features
- Instant theobromine dose (mg/kg) with a calm color-coded risk dial
- Side-by-side comparison of what each chocolate type means for your dog
- 'Next 30 minutes' emergency action plan plus a symptom onset timeline
